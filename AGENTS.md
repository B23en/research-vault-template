# AGENTS.md

**Read `./CLAUDE.md` in full before doing anything else in this repository.**

This repository is a Research Vault — a knowledge repository for a single
research topic, operated by an agent. `CLAUDE.md` is its authoritative
configuration, and this file deliberately holds none of its rules: a copy here
would drift out of sync. It exists only because Codex and other
`AGENTS.md`-reading agents do not load `CLAUDE.md` on their own.

The skills live in `.claude/skills/`, also reachable as `.agents/skills`;
`CLAUDE.md` `## Skills` says how to use them.

If you are Claude Code, you already loaded `CLAUDE.md` automatically — ignore
this file.
